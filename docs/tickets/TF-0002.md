## Cambios realizados

- Nuevo archivo `requirements.txt` con:
  - Dependencia directa: `Flask==3.0.3` (único `import` real en `app.py`).
  - Transitivas de Flask fijadas explícitamente con `==` para reproducibilidad:
    `Werkzeug==3.0.6`, `Jinja2==3.1.6`, `MarkupSafe==2.1.5`,
    `itsdangerous==2.2.0`, `click==8.1.8`, `blinker==1.8.2`,
    `importlib-metadata==8.5.0`, `zipp==3.20.2`.
  - Comentarios que explican el entorno verificado (Python 3.8.10), la
    distinción entre dependencia directa y transitivas, y la nota de que
    `importlib-metadata` / `zipp` solo las requiere Flask en Python < 3.10.

  Python < 3.10, por coincidir con el entorno verificado (3.8.10).
