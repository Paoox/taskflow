## Objetivo

Establecer la **capa de abstracción / runtime de IA** de TaskFlow: un límite
estable y **sin dependencias** entre el resto del sistema y cualquier
proveedor/runtime de modelo.

No es "integrar un proveedor real". Es que, cuando en un ticket posterior
(**TF-0025**) conectemos Ollama, baste con:

```
TASKFLOW_AI_PROVIDER=ollama
TASKFLOW_AI_BASE_URL=http://localhost:11434
TASKFLOW_AI_MODEL=<modelo local>
```

**sin tocar** runner, agentes, skills, tools ni contratos de negocio.

TaskFlow no se diseña alrededor de Claude/OpenAI ni de ningún proveedor SaaS. El
runtime objetivo posterior es Ollama con un modelo local; Claude solo se usa
externamente durante el desarrollo y **no** forma parte de la arquitectura de
producción.

## Contexto

Promoción parcial de **BL-18**. TF-0021 fijó `ClienteIA` / `OpcionesIA` /
`RespuestaIA` / `ClienteEco`. TF-0023 construyó el runner, que **recibe un
`ClienteIA` inyectado** y solo usa `cliente.completar(prompt, opciones)`. Faltaba
la pieza que *elige* qué implementación usar y de dónde toma su configuración.

## Decisiones DA-1..DA-12 (fijadas en el checkpoint final)

- **DA-1** — proveedor objetivo = Ollama / endpoint local compatible con OpenAI.
  TF-0024 = solo la abstracción; `ClienteEco` es el proveedor `"eco"` por
  defecto. El modelo llega por `TASKFLOW_AI_MODEL`, nunca hardcodeado.
- **DA-2** — transporte del futuro `ClienteOllama` = **stdlib `urllib.request`**
  (no `httpx`). Ollama es local: `POST` JSON a `localhost` → basta `urllib` +
  `json`, cero dependencias, idéntico en 3.8/3.12. No se decide/implementa aquí.
- **DA-3** — `RespuestaIA` sin cambios. Truncado → `ErrorRespuestaIA` → FALLIDA
  (lo aplicará TF-0025).
- **DA-4** — factoría desacoplada (`crear_cliente()` + registro).
- **DA-5** — errores tipados (`ErrorIA` + 3 subclases) y saneados.
- **DA-6** — Ollama local **no** necesita el tratamiento de un servicio externo:
  sin backoff exponencial, sin rate-limit, sin circuit breaker.
  `TASKFLOW_AI_MAX_RETRIES` default `0` (fail fast); TF-0025 podrá usar `1` para
  el caso "servidor reiniciándose".
- **DA-7** — modelo local ⇒ coste monetario 0. `coste_estimado = 0.0` siempre en
  adaptadores locales. Sin tabla de precios. Métricas útiles: `tokens_*` y
  `duracion_s` (ya existen).
- **DA-8** — `TASKFLOW_AI_*` = `PROVIDER`, `BASE_URL`, `MODEL`, `TIMEOUT`,
  `API_KEY` (slot reservado), `MAX_RETRIES`. Cubre Ollama y OpenAI-compat sin
  más cambios de config.
- **DA-9** — tests **cero red / cero sockets**.
- **DA-10** — smoke test contra Ollama = **manual, fuera de CI** (procedimiento
  se documenta en TF-0025).
- **DA-11** — Python 3.8 (dev) / 3.12 (Docker/CI): **no se cambia**. TF-0024 usa
  solo stdlib + deps existentes. `urllib` de TF-0025 tampoco fuerza subir.
- **DA-12** — firma de fábrica = `Callable[[], ClienteIA]`; el `lambda` del
  registro lee `TASKFLOW_AI_*`; el adaptador recibe kwargs explícitos y no
  importa `src.config`.

## Contrato factoría → `ClienteIA` → runner

```python
config.proveedor_ia()   -> "eco" (default) | "ollama" | ...
config.ai_base_url()     -> str   ("")
config.ai_model()        -> str   ("")
config.ai_timeout()      -> float (120.0)   # no numérico -> ValueError
config.ai_api_key()      -> str | None
config.ai_max_retries()  -> int   (0)       # no numérico -> ValueError

registro.registrar(nombre, fabrica: Callable[[], ClienteIA]) -> None   # colisión -> ErrorConfiguracionIA
registro.obtener(nombre) -> FabricaCliente                              # ausente  -> ErrorConfiguracionIA
registro.nombres()       -> tuple[str, ...]
registro.quitar(nombre)  -> None

crear_cliente() -> ClienteIA
#   = registro.obtener(config.proveedor_ia())()      # solo lanza subclases de ErrorIA

# El LLAMADOR construye e inyecta; el runner NO llama a crear_cliente():
#   cliente = crear_cliente()
#   ejecutar_agente(entrada, cliente, definicion, opciones=..., repositorio=...)
```

Encaje futuro de Ollama (TF-0025), sin tocar nada de arriba:

```python
# src/ai/ollama.py
class ClienteOllama:                 # implementa ClienteIA por estructura
    def __init__(self, base_url, modelo, timeout, reintentos): ...
    def completar(self, prompt, opciones): ...   # urllib -> POST {base_url}/api/generate
registrar("ollama", lambda: ClienteOllama(
    base_url=config.ai_base_url(), modelo=config.ai_model(),
    timeout=config.ai_timeout(), reintentos=config.ai_max_retries()))
```
