# TF-0009 — obtener_tareas() preserva fecha_creacion

## Estado

DONE

## Tipo

BUG

## Prioridad

P2

## Objetivo

`DBManager.obtener_tareas()` debe devolver el `fecha_creacion` **almacenado** de
cada tarea, no un valor nuevo generado con `datetime.now()` en cada lectura.

## Contexto

Promoción de **BL-02** (`docs/BACKLOG.md`).

`crear_tarea()` persiste correctamente `tarea._fecha_creacion` en la columna
`fecha_creacion`. Pero `obtener_tareas()` reconstruía cada `Tarea` **sin** pasar
ese campo; el constructor de `Tarea`, al recibir `fecha_creacion=None`, lo
rellena con `datetime.now().strftime(...)`. Resultado: el valor real guardado
nunca se leía y cada llamada a `obtener_tareas()` devolvía un `fecha_creacion`
distinto (el "ahora" de esa lectura).

Hoy `index.html` no muestra ese campo, así que el efecto visible es nulo, pero
`to_dict()` lo expone y cualquier vista futura de detalle/edición de tareas
(BL-04) mostraría una fecha de creación incorrecta.

## Cambios realizados

- **`src/database.py`**: en el bucle de `obtener_tareas()`, se añade
  `fecha_creacion=fila['fecha_creacion']` a la construcción de cada `Tarea`.
  (+1 línea efectiva; reindentado menor de la llamada.)
- **`tests/test_database.py`**: nueva clase `TestFechaCreacion` con 4 tests
  (preservación del valor almacenado, `to_dict()` coherente, estabilidad entre
  lecturas consecutivas, coincidencia con lo que persistió `crear_tarea()`).
- **`docs/BACKLOG.md`**: `BL-02` → `PROMOTED`, `Ticket = TF-0009`.

**Sin cambios** en `src/modelos.py` (el constructor ya soportaba `fecha_creacion`),
`app.py`, plantillas, `crear_tarea()`, arquitectura ni dependencias.

## Decisiones y riesgos

- **R1 (muy bajo)** — Filas legacy con `fecha_creacion` NULL/vacío (insertadas
  fuera de `crear_tarea()`): al pasar un valor falsy, el constructor mantiene el
  fallback `now()` actual → sin regresión.
- **R2 (bajo)** — Ningún consumidor asumía "`fecha_creacion` ≈ ahora": ningún
  test lo hacía y `index.html` no muestra el campo.
- **R3 (nulo)** — Impacto arquitectónico: ninguno; solo la ruta de lectura.

## Dependencias
