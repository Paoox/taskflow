## Objetivo

Implementar el adaptador real `ClienteOllama` sobre el contrato `ClienteIA`
definido en TF-0021, conectando TaskFlow con un servidor Ollama local mediante
`POST {BASE_URL}/api/generate`.

## Alcance

- Implementar `ClienteOllama`.
- Transporte mediante `urllib.request` de la librería estándar.
- Registrar el proveedor `ollama` en su propio módulo.
- Obtener configuración mediante `TASKFLOW_AI_*`.
- Mapear respuesta de Ollama a `RespuestaIA`.
- Convertir errores de transporte y respuestas inválidas a la jerarquía
  `ErrorIA`.
- Soportar reintentos configurables, con `0` por defecto.
- Mantener coste estimado en `0.0` para modelos locales.
- Tests unitarios sin red real.
- Smoke test manual contra Ollama real, fuera de CI.

## Decisiones

- DA-1: Ollama es el proveedor real de TF-0025.
- DA-2: transporte exclusivo mediante `urllib.request`.
- DA-3: `done_reason == "length"` se considera truncamiento y produce
  `ErrorRespuestaIA`.
- DA-6: `MAX_RETRIES=0` por defecto; fail fast para Ollama local.
- DA-7: modelos locales tienen `coste_estimado=0.0`.
- DA-9: los tests automatizados no realizan conexiones de red.
- DA-10: la validación contra Ollama real se realiza mediante smoke test manual.
- DA-12: el registro del proveedor ocurre al importar explícitamente
  `src.ai.ollama`.

### Smoke test manual contra Ollama real (DA-10)

Fuera de CI. Requiere un servidor Ollama en marcha con el modelo descargado.

```bash
# 1. Servidor y modelo
ollama serve &
ollama pull qwen2.5:3b

# 2. Configuración del runtime de IA
export TASKFLOW_AI_PROVIDER=ollama
export TASKFLOW_AI_BASE_URL=http://localhost:11434
export TASKFLOW_AI_MODEL=qwen2.5:3b

# 3. Ejercitar el flujo factory -> ClienteOllama -> Ollama -> RespuestaIA
python -c "
import src.ai.ollama  # registra el proveedor 'ollama'
from src.ai import crear_cliente
from src.ai.cliente import OpcionesIA
r = crear_cliente().completar('Responde solo con la palabra: ok', OpcionesIA())
print(repr(r))
assert r.texto and r.modelo == 'qwen2.5:3b' and r.coste_estimado == 0.0
"
```

Resultado esperado: un `RespuestaIA` con `texto` no vacío, `modelo` igual al
configurado, `tokens_entrada`/`tokens_salida` > 0 y `coste_estimado == 0.0`.

Ejecución registrada: realizada con `qwen2.5:3b`, resultado OK
(`coste_estimado=0.0`, flujo `factory → ClienteOllama → Ollama → RespuestaIA`
verificado). No re-ejecutada en la revisión final: el entorno de revisión no
tiene una instancia de Ollama accesible.
